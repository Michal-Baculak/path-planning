# Experiment 1: Testing Weighted Optimization

## Purpose
Checking the correct function of weighted optimization that is based on k<sup>2</sup>  and the total length of the trajectory.  
The core idea of weighted optimization is comparing the calculated values of a given trajectory with the midpoint trajectory, obtaining a normalized, dimensionless result that can be used for weighing. The values of curvature and length without this processing are orders of magnitude different.  
The hypothesis is that we should get visually very similar results with direct length optimization using the established algorithm and with optimization using the new cost function `get_cost_weighted` with the `weight` parameter set to `0`. Similarly, we should achieve comparable results between established k<sup>2</sup> optimization and the one generated by calling `get_cost_weighted` with the `weight` parameter set to `0`.  
Next, we aim to compare the results of combined optimization using `weight` values such as `0.5` to determine if the resulting trajectory saves any lap time. We will also look for visual cues to confirm that the algorithm is functioning correctly.

## Methodology
1. Data sources: `track1_fixed.mat`
2. Script: `get_cost_weighted.m`
3. Key variables:
   - **weight**: Value from the interval [0, 1] (inclusive), determines the weight of cost computation. A value of `1` considers only k<sup>2</sup>, while `0` considers only length.

## Results
### Length Optimization:
- **Length after optimization:**
  - Original cost function: `331.1368`
  - New cost function: `331.1446`
   
- **Lap time after optimization:**
  - Original cost function: `10.3102`
  - New cost function: `10.3008`

### k<sup>2</sup> Optimization:
- **k<sup>2</sup> after optimization:**
  - Original cost function: `0.1719`
  - New cost function: `0.1710`
   
- **Lap time after optimization:**
  - Original cost function: `9.4968`
  - New cost function: `9.5168`

### Combined k<sup>2</sup> and Length Optimization (\(w = 0.5\)):
- **Lap time:** `9.0416`
- **Total length:** `368.0217`
- **Total k<sup>2</sup>:** `0.1788`

1. The curvature and length optimizations are both very similar to the established method, visually and quantitatively.  
2. Combining the two metrics provides better optimization than either method alone.
